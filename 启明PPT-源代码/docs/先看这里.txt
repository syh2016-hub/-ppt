启明 PPT · 先看这里
====================

1. 双击「启明PPT.exe」启动。
   如果 Windows 提示 SmartScreen，选择“更多信息 → 仍要运行”。

2. 首次使用请注册账号。
   邀请码：songyonghao2016
   （区分大小写，必须完全一致）
   如果管理员开启了邮箱验证码，还需要填写邮箱并点击「获取验证码」。

3. 管理后台：登录管理员账号后，点击左下角「管理后台」。
   初始账号：admin
   初始密码：Admin@2016
   首次登录后请立刻在「系统设置」中修改密码。
   初始密码也保存在：
   %LOCALAPPDATA%\QimingPPT\管理员初始账号.txt

4. 参考素材：
   在「新建演示」页可以上传图片或文档。
   - PDF / Word / PPT / Excel / TXT / Markdown / CSV 会提取正文，
     生成大纲时会优先参考。
   - 图片会提取配色；勾选后可以把第一张图用作封面背景。
   - 旧版 .doc / .ppt / .xls 需要本机安装 LibreOffice 才能解析。
   - 课文朗读时，课文照片/截图会调用 Windows OCR 识别文字；扫描版 PDF 暂不自动 OCR。
   - 一次最多 8 个，单个不超过 20 MB。

5. 邮箱验证码：
   默认关闭。管理员在「系统设置 → 注册邮箱验证码」中填写
   SMTP 服务器、端口、授权码、发件邮箱，保存并发送测试邮件。
   测试成功后，再打开「开启邮箱验证码」并保存。
   QQ 邮箱示例：smtp.qq.com / 465 / SSL。
   密码要填 SMTP 授权码，不是邮箱登录密码。
   短信验证码需要第三方付费短信服务，本版本未包含。

6. 软件完全免费，导出 PPTX / PDF 都没有水印。
   PDF 导出需要本机安装 LibreOffice。

7. 数据目录：
   %LOCALAPPDATA%\QimingPPT\
   可在「AI 与账户 → 数据与关于」中打开。
   参考素材保存在 references 子目录，只在本机处理。

8. AI 密钥不是必须的。
   不配置时使用离线的「启明内置 AI」；
   配置 DeepSeek / 豆包后可以获得更好的文案质量。
   管理后台 → 系统设置 → 全局 AI 引擎。

9. 输出语言：新建演示页可选择「中文」或「English」，英文课件会用英文大纲和英文声音。

10. 页数：新建演示可设置 6—50 页；
   20 页以上会自动拆分更多章节，40 页以上建议 6 个章节。

11. 旁白声音：
    在「生成演示」页选择中文声音和英文声音，点「试听」可先听。
    可选温柔女声、成人男声、中文童声、英文童声；英文课文自动用英文声音。
    课文朗读：上传含课文的文档或图片，点「从参考文档识别」，生成时自动插入朗读页。

12. 生成动画 / 旁白 / 动态视频：
    在最后一步按需勾选。
   - 动画：每一页元素入场 + 翻页转场
   - 旁白：Windows 中文语音合成，逐页自动播放
   - 视频：本地生成抽象动态封面，循环播放
   - 自动翻页：有旁白时按讲解时长前进

13. 需要 PDF：
    安装 LibreOffice 后，在下载页点击「下载 PDF」。
    没有 LibreOffice 时请直接下载 PPTX。

更多说明见 README.md。
